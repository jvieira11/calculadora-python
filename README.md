# 🧮 Calculadora em Python

Calculadora de terminal com menu interativo, feita em Python puro para praticar laços de repetição, condicionais e tratamento de casos especiais.

## Funcionalidades

- Menu com soma, subtração, multiplicação e divisão
- Bloqueia divisão por zero com mensagem de erro
- Continua rodando até o usuário escolher sair

## Tecnologias

- Python 3 (sem bibliotecas externas)

## Como rodar

```bash
git clone https://github.com/jvieira11/calculadora-python.git
cd calculadora-python
python calculadora.py
```
